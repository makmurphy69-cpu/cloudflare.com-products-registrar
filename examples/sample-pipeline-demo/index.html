Drawings → video → cut → music: the full pipeline

Every file on this page is genuine, unedited output from the tools it names — nothing here was touched up by hand.

This walks through four tools working together end to end: Video Forge turns a set of drawings into an animated video, Clip Forge trims it and adds a caption, Music Forge generates an original instrumental track from scratch, and Merge Forge combines the trimmed clip with that music into one final video. Each stage below plays the actual file produced at that step.

Stage 1 — Video Forge

Three sample drawings become a video

Video Forge's built-in "Try a sample" doodles (a sunny day, a house, a waving figure), animated with Ken Burns pan/zoom, a crossfade between each, and a title card — rendered straight to a downloadable video, no music yet.
