Want to use your own domain instead of github.io? (click for steps)
  1. Buy a domain from any registrar — Namecheap, Porkbun, Cloudflare Registrar, etc. (typically $9–15/year for a .com).
  2. Point its DNS at GitHub Pages. In your registrar's DNS settings, add four A records for the root domain (e.g. yourbusiness.com), all pointing to:
    185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
    Optionally also add a CNAME record for www pointing to your-username.github.io.
  3. Add the domain in GitHub. In your published repo, go to Settings → Pages → Custom domain, type your domain, and click Save. GitHub adds a CNAME file to the repo automatically.
  4. Wait for the DNS check. GitHub verifies the DNS records before it can issue a certificate — this is usually quick but can occasionally take a few hours. If it seems stuck for a long time, click Remove, wait a few seconds, then re-enter the domain and Save again to force a fresh check.
  5. Turn on Enforce HTTPS. Once the check succeeds (a green "DNS check successful"), tick the "Enforce HTTPS" box in that same settings page — this makes sure visitors always get the secure, padlocked version of your site.

DNS changes can take anywhere from a few minutes to 24 hours to fully propagate worldwide — if your domain doesn't work immediately, that's normal, just give it time.
